# Mobile AI processing consent

Railway resolves a single provider, model and endpoint for the mobile AI calls. Before deploying this change, verify that route against the live service and verify each recipient and its applicable retention with the provider dashboard or account terms. Set `MOBILE_AI_DISCLOSURE` to a JSON object containing `provider`, `model`, `api_base` (null for the default API endpoint), `recipients` (display names), and `retention` (verified, customer-facing explanation). For OpenRouter, also set `openrouter_only` to the verified downstream provider slugs. Mobile requests disable provider fallbacks for that route. Do not use model aliases that can select another model. No keys belong in this variable. Apply the matching Supabase migration before deployment.

Missing or mismatched disclosure configuration blocks mobile AI processing. The authenticated GET/PUT `/api/v1/mobile/ai-consent` return the current disclosure and store only the account, disclosure version, decision and timestamp. A changed disclosure requires a new decision. Upload, processing retry, full tailoring (both endpoints), the worker and keyword application require acceptance. The transport rechecks the decision before each dispatched completion. A request already sent to a provider cannot be recalled. Changes within automatic transport retries should be treated as part of the same dispatched request. Saved CV reading, editing, deletion of original files, deterministic editor scoring, confirming a completed draft and exporting saved PDFs stay available.

Extraction from PDF or DOCX happens on Railway. The parser receives the extracted CV text, potentially including contact information. Tailoring uses structured CV contents and job descriptions; keyword processing uses job terms and relevant CV content. Railway's mounted data directory also holds working resumes, jobs and revisions. Supabase holds original files in a private bucket, CV registry metadata and tailoring jobs/drafts. Draft expiry limits reuse and does not establish a deletion schedule. Verify storage, volume, backups and provider retention independently.
